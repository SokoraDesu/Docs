# Develop Sokora

We're thankful that you're willing to contribute to Sokora! This overall guide will help you get things done in a way appropriate for this project.

!!!question "Looking for a guide to self-hosting?"
    If your only goal is a self-hosted instance of Sokora, you only care about the [first steps](./101.md) page, which teaches you how to install and run Sokora.

Welcome! This section and all its pages will help you understand the Sokora codebase more easily and work with it effectively, both for the official team and for any wannabe contributor.

Serve yourself with the pages on the left sidebar.

Note that these docs are a work in progress, not everything is well documented yet.
