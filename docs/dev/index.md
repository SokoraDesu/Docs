# Develop Sokora

We're thankful that you're willing to contribute to Sokora! This overall guide will help you get things done in a way appropriate for this project.

!!!question "Looking for a guide to self-hosting?"
    If your only goal is a self-hosted instance of Sokora, you only care about the [first steps](./101.md) page, which teaches you how to install and run Sokora.

!!!caution "Rewrite in progress"
    Sokora is being restructured (or “partially rewritten”, if you will) within [this fork](https://github.com/zakahacecosas/sokora) (“MVC branch” from now on). Until this is finished, documentation is not guaranteed to be up to date. **In some places, this documentation already reflects the MVC branch’s state and not Sokora’s current one**, while other places are still up to date with Sokora’s main branch.

    Anyway, **it is specified (in “Status”-labeled admonitions) on each point of the site with which branch is the text up to date, and how is the other branch doing.**

    Ideally, we’ll merge the restructuring before November 2026, ending this weird situation. Until then you’re **still expected to use the main branch** (SokoraDesu/Sokora).
