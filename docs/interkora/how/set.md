# Set and reset

You can modify settings with Interkora.

For example, you can set them to a specific value.

```bash
soko$set leveling enabled false
```

You can also reset a setting to its default value, with `reset`, or reset its whole category with `drop`.

```bash
soko$reset leveling enabled

soko$drop welcome
```
